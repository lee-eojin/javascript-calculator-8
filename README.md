# javascript-calculator-precourse

## 기능 목록

- [ ] 문자열 입력받기 (`@woowacourse/mission-utils`의 Console.readLineAsync)
- [ ] 빈 문자열이면 0 반환
- [ ] 커스텀 구분자 있는지 확인 (`//`로 시작하는지)
- [ ] 커스텀 구분자면 구분자 추출하고 문자열 분리
- [ ] 아니면 기본 구분자(쉼표, 콜론)로 분리
- [ ] 분리한 문자열들 숫자로 변환
- [ ] 음수 있으면 에러 -> 애플리케이션 종료
- [ ] 숫자들 다 더하기
- [ ] 결과 출력 (Console.print)
